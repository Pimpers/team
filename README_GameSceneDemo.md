# GameScene - 핵심 루프 플레이 가능한 프로토타입

## 조작
- 이동: WASD 또는 방향키
- **공격: 마우스 왼쪽 클릭** — 클릭 시 마우스 커서 방향으로 일정 범위/각도(기본 사거리 2.5, 부채꼴 100도) 안에 있는 몬스터/보스에게 공격력만큼 데미지. **몬스터/보스를 죽이는 유일한 방법입니다.**
- 몬스터/보스에게 그냥 다가가서 부딪히면 플레이어만 접촉 데미지를 받고 살짝 밀려납니다 (몬스터는 안 죽음) — 가만히 있으면 계속 얻어맞으니 주의하세요.
- 맞을 때마다 짧게 피격(Take Damage) 애니메이션이 재생되고 자동으로 Idle로 돌아옵니다.
- **점프: Space** — 짧게 점프 애니메이션이 재생되고, 그동안은 접촉 데미지를 받지 않습니다 (회피기 역할). 이동은 점프 중에도 계속 가능하고, 쿨다운 0.6초.
- **사망**: HP가 0이 되면 Death 애니메이션이 재생되고 마지막 프레임에서 멈춥니다. 이동/공격/점프 등 모든 입력이 그 순간부터 멈춰요 (이전에는 죽어도 계속 움직이고 공격할 수 있었던 빠진 부분이었음).

## 스테이지 진행 방식 (스컬 스타일 - 걸어서 이동)
메뉴형 맵 화면이 아니라, **스컬(Skul: The Hero Slayer)처럼 실제로 걸어서 다음 구역으로 넘어가는 방식**입니다.
- Stage 1(x≈0), Stage 2(x≈20), Boss(x≈40) 구역이 월드 공간에 나란히 배치되어 있고, 셋 다 씬 시작부터 계속 존재합니다 (따로 활성화/비활성화 안 함).
- 카메라(`CameraFollow.cs`)가 플레이어를 좌우로 따라다녀서, 오른쪽으로 계속 걸어가면 자연스럽게 다음 스테이지 구역이 화면에 들어옵니다.
- 카드 선택 팝업은 그대로 스테이지 클리어 시 뜨지만, 고르고 나면 별도 확인 절차 없이 **그냥 오른쪽으로 걸어가면** 다음 스테이지 몬스터들이 기다리고 있습니다.
- (단순화: 아직 스테이지 사이를 막는 문/벽은 없어서, 이론상 몬스터를 안 잡고 앞으로 달려가는 것도 가능합니다 — 필요하면 막는 기믹을 추가할 수 있어요.)

## 루프 흐름
1. **Stage 1**: 몬스터 2마리 배치. 다가가면 플레이어 공격력만큼 몬스터 체력이 깎이고, 동시에 몬스터의 접촉 데미지가 플레이어에게 들어갑니다 (일반 몬스터는 체력 1이라 한 번 스치면 처치됨).
2. 몬스터를 모두 처치하면 **카드 선택 화면**이 뜹니다 (Attack +1 / Speed +15% / Max HP +20 중 1장). 같은 카드를 나중에 또 고르면 효과가 누적됩니다 (레벨업 느낌).
3. 카드를 고르면 바로 오른쪽으로 걸어가서 **Stage 2**(몬스터 2마리, 약간 더 강함)로 진입 → 클리어 후 카드 선택 한 번 더.
4. 다시 오른쪽으로 걸어가면 **Boss 구역**. 보스(체력 4, 데미지/골드 더 높음)를 처치하면 런 성공.
5. 플레이어 HP가 0 이하가 되면 그 즉시 런 실패로 처리됩니다 (그때까지 모은 골드는 그대로 인정).
6. 결과 화면에서 이번 판 골드로 **영구 스탯 강화**(공격력/이동속도/체력)를 살 수 있고, 안 쓴 골드는 사라집니다. 강화 레벨은 `PlayerPrefs`에 저장되어 다음 런에도 유지됩니다.
7. "Retry" 버튼을 누르면 GameScene을 다시 로드해서 새 런을 시작합니다 (카드 효과는 초기화, 영구 스탯은 유지).

## 구성 스크립트 (Assets/CS/)
- `PlayerStats.cs` — 공격력/이동속도/체력, 골드, 메타 강화 레벨(PlayerPrefs) 관리
- `PlayerController2D.cs` — WASD 이동 + Idle/Run 애니메이션 전환 (Meow Knight 스프라이트 사용)
- `Enemy.cs` — 몬스터/보스 공용 스크립트 (거리 기반 접촉 판정, Collider/Rigidbody 없이 동작)
- `RunManager.cs` — 스테이지 진행, HUD 갱신, 카드 선택/결과 화면 트리거
- `PlayerAttack.cs` — 마우스 왼쪽 클릭으로 커서 방향의 적을 공격
- `CardDraftUI.cs` — 카드 3장 선택 패널
- `ResultUI.cs` — 결과 화면 + 메타 강화 상점 + 재시작
- `CameraFollow.cs` — 카메라가 플레이어를 좌우로 따라다님 (스테이지 간 이동 연출용)

## 사용 안 하는 것 (남아있지만 꺼져있음)
- `MapUI.cs`와 씬의 `MapController`/`MapPanel` — 이전에 만든 클릭형 맵 팝업인데, "걸어서 이동" 방식으로 바꾸면서 더 이상 호출 안 합니다. 완전히 지우고 싶으면 말씀해주세요.

## 의도적으로 단순화한 부분 (프로토타입 범위)
- 몬스터/보스 판정은 실제 Unity 물리(Collider2D/Rigidbody2D) 대신 **거리 체크**로 구현했습니다. 에디터에서 검증 없이 물리 컴포넌트를 직접 씬 파일에 써넣는 건 실수 위험이 커서, 더 안전한 방식을 택했습니다. 나중에 실제 충돌체 기반으로 바꾸고 싶으면 말씀해주세요.
- 카드 풀은 3종류(공격/속도/체력) 고정입니다. 지난번에 논의한 15종 카드 풀로 확장하려면 `CardDraftUI.cs`를 카드 데이터베이스 기반으로 리팩터링하면 됩니다.
- 몬스터/보스 그래픽은 Meowolas 스프라이트를 재사용한 자리표시자입니다.
- 공격 애니메이션이나 피격 이펙트는 아직 없고, 부딪히면 즉시 판정만 일어납니다.

## 확인 방법
Unity 에디터에서 `GameScene.unity`를 열고 Play 모드로 실행해서 위 흐름이 그대로 진행되는지 확인해주세요.
